# 📚 Student Management System (Python OOP)

## 📌 Overview
This project is a console-based Student Management System built using Python and Object-Oriented Programming principles.

The system supports role-based access for Students and Administrators.

## 🚀 Features
- Student Signup & Login
- Admin Signup & Login
- View all students (Admin)
- Delete student (Admin)
- Role-based access control

## 🛠️ Technologies Used
- Python 3
- Object-Oriented Programming (OOP)

## ▶️ How to Run
Run the following command:

python student_record.py
